截至2025年末，全国超5353万人享受老年人津补贴
据民政部网站消息，7月31日，民政部、全国老龄办发布《2025年度国家老龄事业发展公报》。公报显示，2025年，我国老年人福利津补贴覆盖范围继续扩大。截至2025年末，全国享受老年人津补贴人数5353.8万人，其中高龄津贴4145.9万人，护理补贴91.6万人，养老服务补贴585.8万人，综合补贴530.5 万人。2025 年，全国各级财政用于养老服务和老年人福利领域的支出约1200亿元，其中中央财政支出超300亿元。
